# xlsx2csv Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Go library that converts `.xlsx` to `[][]string` with typed cell errors, encoding auto-detect/override, `Inspect` metadata, benchmarks, and low-allocation hot path.

**Architecture:** First-party OOXML reader: buffer `io.Reader` → zip → charset decode XML parts → parse shared strings + sheet → dense `[][]string`. Public API in package root; OOXML details under `internal/ooxml`.

**Tech Stack:** Go 1.22+, stdlib (`archive/zip`, `encoding/xml`, `errors`, `io`), `golang.org/x/text` (encoding + charset detect).

**Spec:** `docs/superpowers/specs/2026-07-22-xlsx2csv-design.md`

## Global Constraints

- `.xlsx` only — no `.xls`, no excelize
- No formulas — formula/`t="e"` cells are `CellError`
- Keep file text literals for numbers/strings (no float→fmt round-trip)
- `ErrorLimit`: default `1`; `0` treated as `1`; `-1` = collect all
- Bad cells write `ErrorPlaceholder` (default `""`); always return partial rows once sheet parse started
- Override encoding via `encoding.Encoding`; nil = auto-detect
- **TDD mandatory every task:** write failing test → run → see fail for right reason → minimal code → run pass → refactor → commit. No production code before a failing test. Use `bun test` is N/A here — run with `go test`.
- Profile + alloc-fix loop before calling hot path done (Task 10)

```go
func buildXLSX(parts map[string][]byte) []byte {
	var buf bytes.Buffer

		}
```

```go
package xlsx2csv

import "golang.org/x/text/encoding"

type Option func(*config)

type config struct {
	sheetIndex  int
	sheetName   string
	useName     bool
	enc         encoding.Encoding
	errorLimit  int
	placeholder string
}

func apply(opts []Option) config {
	cfg := config{errorLimit: 1, placeholder: ""}
	for _, opt := range opts {
		if opt != nil {
			opt(&cfg)
		}
	}
	if cfg.errorLimit == 0 {
		cfg.errorLimit = 1
	}
	return cfg
}

func WithSheetIndex(i int) Option {
	return func(c *config) { c.sheetIndex = i; c.useName = false }
}
func WithSheetName(name string) Option {
	return func(c *config) { c.sheetName = name; c.useName = true }
}
func WithEncoding(enc encoding.Encoding) Option {
	return func(c *config) { c.enc = enc }
}
func WithErrorLimit(n int) Option {
	return func(c *config) { c.errorLimit = n }
}
func WithErrorPlaceholder(s string) Option {
	return func(c *config) { c.placeholder = s }
}
```

```go
func decodeXML(raw []byte, override encoding.Encoding) ([]byte, string, error) {
	enc := override
	name := ""
	if enc == nil {
		enc, name = detectEncoding(raw)
	} else {
		name = encodingName(enc)
	}
	if enc == nil || name == "utf-8" || name == "UTF-8" {
		return raw, "utf-8", nil
	}
	decoded, err := enc.NewDecoder().Bytes(raw)
	if err != nil {
		return nil, name, err
	}
	// normalize xml decl to utf-8 for xml.Decoder
	decoded = rewriteXMLDeclEncoding(decoded, "UTF-8")
	return decoded, name, nil
}
```
